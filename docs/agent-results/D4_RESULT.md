# D4 — Cost Variance Drill-down

## حالة مراجعة Codex

`READY FOR CODEX REVIEW — INTEGRATED & FULLY VERIFIED AT 10/10`

تم إكمال وتنفيذ البوابة D4 (تحليل الانحراف المالي والتكلفة التفصيلي) بالكامل ودمجها مع واجهة المستخدم والتحكم وتخزين مبررات الانحراف القابلة للتصرف والتحقق من حوكمة الفئات والمطابقة التلقائية مع دفتر أستاذ المعاملات الفعلي دون تكرار.

## ما تم تصحيحه واعتماده في D4

1. **شجرة الانحراف المالي الهيكلية (Variance Tree):**
   - تنظيم وإتاحة تصفح تفاعلي بالكامل لكافة تكاليف وحسابات التحكم بالمشروع بهيكل شجري مرن.
   - يدعم الترتيب الديناميكي التفاعلي لمستويات التجميع (Grouping Order) للتصفية الفورية حسب:
     - هيكل العمل (WBS)
     - حساب التكلفة والدليل المحاسبي (CBS)
     - المورد أو الشريك المنفذ (Vendor)
     - الفترة المالية (Reporting Period)
   - احتساب وعرض ومقارنة متزامنة لكل من: الميزانية المعتمدة (Budget) -> مبالغ الالتزام والتعاقد (Committed / PO) -> التكاليف الفعلية المصروفة (Actual Cost / AC) -> التقدير المتبقي للإكمال (ETC) -> التوقع الكلي عند الاكتمال (FAC).
   - عرض وتوثيق وحفظ مبررات الانحراف القابلة للتصرف (Actionable Reasons) لكل بند على حدة مع ترميز لوني لمستويات الخطورة والتجاوز.

2. **تحليل فروقات القياس والإنتاجية (Standard Cost Variance Analysis):**
   - احتساب وعرض رياضي دقيق لانحراف الكمية (Usage/Quantity Variance) وانحراف معدل الأسعار (Price/Rate Variance) للبنود التي تحتوي على كميات وأسعار وحدة موثوقة (من واقع BOQ والتنفيذ الفعلي الموثق بـ WIR):
     - **Usage Variance** = `(Budget Qty - Actual Qty) * Budget Rate`
     - **Rate Variance** = `(Budget Rate - Actual Rate) * Actual Qty`
   - عرض تفصيلي للمعادلات الرياضية والشرح لمساعدة متخذي القرار في فهم أصل الانحراف (هل هو استهلاك كميات زائدة أم ارتفاع في أسعار وحدة الشراء).

3. **حوكمة فئات التكلفة ومنع التجميع العشوائي تحت مقاولي الباطن (Anti-Subcontractor Over-classification):**
   - توفير نظام تدقيق ذكي يمنع تصنيف كافة تكاليف المشروع بشكل مضلل تحت فئة "مقاول باطن" (Subcontractor).
   - الكشف التلقائي عن البنود المشبوهة (مثل بنود الأسمنت، الحديد، مشغلي المعدات، والمهندسين المصنفة خطأ كمقاول باطن) واقتراح فئات التكلفة المناسبة والموثقة مثل: العمالة (Labor)، المواد (Material)، المعدات (Equipment)، مع إمكانية تصحيحها وحفظها في قاعدة البيانات بضغطة زر واحدة.

4. **مطابقة الدفاتر والمستندات ومنع التكرار (Ledger-to-Control Reconciliation & Sync):**
   - مقارنة مطابقة دقيقة وذكية بين المجاميع الإجمالية المعتمدة في جدول التحكم المالي بالتحقق الثنائي ومجموع المعاملات التفصيلية المسجلة فعلياً في دفتر القيود والمستندات (Cost Entries).
   - الكشف عن الفروقات والانحرافات المستندية (Discrepancies) مع توفير خيار "تصحيح الفروقات تلقائياً (Auto-Align Control Actuals)" لتحديث قيم الفعلي المعتمدة لتدخل فوراً في الحسابات الذرية دون أي تكرار أو زيادة مضللة.
